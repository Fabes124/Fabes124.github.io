# Fabian Espinoza de Osambela — academic website

Built on the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template.

Where to edit:

- `_config.yml` — name, sidebar bio, email, profile links
- `_pages/about.md` — home page
- `_pages/cv.md` — CV page
- `_publications/`, `_talks/`, `_teaching/` — one Markdown file per item; copy an existing file to add a new one
- `images/profile.png` — sidebar photo
- `files/` — PDFs (e.g. `files/cv.pdf` is served at `/files/cv.pdf`)

The site rebuilds automatically through GitHub Actions on every commit to `main`.
